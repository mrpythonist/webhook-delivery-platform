# Support

## Where to Get Help

- **Usage questions and bug reports:** open an issue at
  https://github.com/mrpythonist/webhook-delivery-platform/issues.
  Use the bug report template for bugs and the feature request template for
  ideas. Include the steps you followed, what you expected, and what happened.
- **Documentation:** start with the README, then `docs/architecture.md`,
  `docs/development.md`, and `docs/api.md` in this repository.
- **General contact:** https://mrpythonist.com

## Before Opening an Issue

1. Check the README "Limitations" section and the troubleshooting notes in
   `docs/development.md`. The Docker and migration steps have not been run
   against a live database yet, so setup problems in that area are known gaps.
2. Check existing issues to see if your question is already answered.
3. Include versions where relevant: Node.js version, whether you used Docker
   Compose or a local Postgres/Redis setup, and the exact command that failed.

## What Support Covers

This is a personal project maintained in spare time. Help is provided on a
best-effort basis:

- Help understanding the code, the API, and the retry behavior is welcome.
- Bug fixes for reproducible problems are welcome as pull requests.
- There is no guaranteed response time and no paid support tier.

## Security Issues

Do not report security vulnerabilities in a public issue. Follow
`SECURITY.md` instead.
